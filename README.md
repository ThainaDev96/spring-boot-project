## Executando o projeto

### Windows (PowerShell)

```powershell
.\mvnw.cmd spring-boot:run
```

No Prompt de Comando (CMD):

```cmd
mvnw.cmd spring-boot:run
```

### Testando

Abra no navegador `http://localhost:8080/api/programas/57`, ou use o terminal.

No PowerShell:

```powershell
curl.exe http://localhost:8080/api/programas/57
```
